# Manufacturing Finance (built app files)

This repository contains only the built, static files of the Manufacturing Finance app, served by GitHub Pages.

- No business records, invoices, backups, personal data, secrets or credentials are stored here.
- The app keeps all records on the user's own device. Nothing is uploaded.
- The two sample bills are fictional test documents.

Source code is kept in a separate private repository. Build: source commit 671da9b.
